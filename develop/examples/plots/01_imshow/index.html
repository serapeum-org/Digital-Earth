    1 · imshow¶

    Map.imshow renders a raster as a pixel grid (cleopatra ArrayGlyph, kind="imshow"). Map reprojects via pyramids and draws on a shared axes; colorbar() adds one aggregated bar.

    Setup — inline plots and the path to the bundled Lisbon DEM.

    ROOT = ROOT.parent

from pyramids.dataset import Dataset
from digitalearth.scene import Map
