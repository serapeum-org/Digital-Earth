    Interactive web maps with InteractiveMap¶

    digitalearth.interactive is the interactive-2D web-map tier: the same pyramids data and auto-style pipeline as the static Map, rendered through the HoloViz stack (GeoViews → HoloViews → Bokeh, plus Datashader and Panel) so the result pans, zooms and hovers in the browser.

    It is a renderer, not a GIS engine: every layer is built from pyramids-sourced arrays / GeoDataFrames and all CRS work happens upstream in pyramids — never xarray/rasterio/cartopy. The engine import is lazy, so import digitalearth.interactive works without the interactive extra; only a builder call needs it.

    These notebooks use the bundled Rhine-basin hydrology data (gauges, river network, basin) and a global WorldClim temperature stack — all real files under examples/data/.

    Plots in this notebook are shown as static images via the show(...) helper so they are visible in every viewer. The maps are genuinely interactive — run the notebook live (Jupyter/Bokeh) for pan, zoom and hover.

    Setup — find the repo root, load the backends and define show(...). Every notebook starts like this.

    import warnings
warnings.filterwarnings("ignore")            # hide backend-mismatch style warnings in the docs

from pathlib import Path

# Resolve the repo root so the bundled sample data is found whether this runs from
# docs/examples/interactive/ (mkdocs) or the repository root.
ROOT = Path.cwd()
while not (ROOT / "examples" / "data" / "LisbonElevation.tif").exists() and ROOT != ROOT.parent:
    ROOT = ROOT.parent
DATA = ROOT / "examples" / "data"

import io
from IPython.display import Image
import matplotlib.pyplot as plt
import holoviews as hv
hv.extension("bokeh", "matplotlib")          # Bokeh = interactive (live); matplotlib = static image for docs

def show(m, dpi=96):
    """Render an InteractiveMap to a static PNG so it displays in any viewer.

    The maps are interactive Bokeh under the hood — run this notebook in a live Jupyter/Bokeh
    session for pan / zoom / hover. Here we render to a PNG image so the plot is visible in VS Code,
    on GitHub and in the docs without a running kernel.
    """
    fig = hv.render(m.render(), backend="matplotlib")
    buf = io.BytesIO()
    fig.savefig(buf, format="png", dpi=dpi, bbox_inches="tight")
    plt.close(fig)
    return Image(data=buf.getvalue())

    from pyramids.dataset import Dataset
from digitalearth.interactive import InteractiveMap

dem = Dataset.read_file(str(DATA / "LisbonElevation.tif"))
m = InteractiveMap(crs=dem.epsg, title="Lisbon elevation")
m.image(dem, cmap="terrain")
show(m)
