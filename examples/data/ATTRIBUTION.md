# Example data sources

Third-party data bundled here for the documentation notebooks, with the attribution each source requires.

## `germany_adm1.geojson`

Germany's 16 federal states (ADM1), downloaded through
[earthlens](https://github.com/serapeum-org/earthlens)' `admin` backend from
**geoBoundaries (gbOpen)** and simplified to a 0.005-degree tolerance to keep the file small.

- Licence: **CC-BY-4.0**
- Citation: Runfola, D. et al. (2020) *geoBoundaries: A global database of political administrative
  boundaries.* PLoS ONE 15(4): e0231866. <https://www.geoboundaries.org/>

Used by `docs/examples/plots/27_voronoi.ipynb`, `30_kde.ipynb`, `31_cartogram.ipynb` and `34_labels.ipynb`.
